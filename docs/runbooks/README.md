# Operational runbooks

[Documentation](../README.md) | [Repository map](../engineering/repository-layout.md)

Reserved for package-owned setup, recovery, repeatable reconstruction and demo
operation runbooks (#3/#13 and each source/workload owner). Each real runbook must
state prerequisites/rights, exact approved scope, commands, verification, recovery
and manual limitations. Do not document fictional successful rehearsals.
Existing [identity pilot guidance](../dev-identity-pilot.md) stays at its stable
path. No rebuild or deployment procedure is implemented by this folder.
