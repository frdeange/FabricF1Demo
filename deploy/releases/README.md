# Release evidence contract

[Deployment](../README.md) | [Repository map](../../docs/engineering/repository-layout.md)

Reserved (#13/#12; #8 is historical foundation evidence). Routine orchestration
requires an assigned deployment follow-up package before execution.
A future release record must identify commit SHA, pinned
tool/lock versions, artifact hashes, dataset version/digests, resource ownership,
sanitized binding mappings, checks, approvals and recovery limitations.
Promote an identified tested revision, not floating HEAD.
Public records exclude secrets, tenant details and private target mappings.
No release record or proof of deployment is generated by this scaffold.
