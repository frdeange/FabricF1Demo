# Deployment contracts

[Repository map](../docs/engineering/repository-layout.md)

Reserved for [environment contracts](environments/README.md) and
[release evidence contracts](releases/README.md). #8 is closed foundation evidence,
not future orchestration ownership. Assign a deployment follow-up package before
execution, coordinating readiness #3, app qualification #9 and workload owners;
no deploy runner/workflow exists here.
One writer per artifact/destination, pinned tools and explicit approved scope are
required. Schema migration, item publication and data seeding remain separate
operations; no implicit reset or orphan deletion.
See the [ownership matrix](../docs/deployment-ownership-support-matrix.md).
